What is Sudoku?

Sudoku is a board game with 9X9 grid, having 9 internal sub grids of size 3X3 without overlapping each other.

In each column and rows and sub grid, the player has to fill no’s from 1 to 9, without any duplicate value.

It sounds easy, but in reality it's not that simple, sudoku has different levels starting from easy to extreame.
